# Jisr App

A mobile platform for student career readiness and peer-to-peer mentoring.

## Overview
Jisr connects university students to share academic skills, receive AI-powered career roadmaps, and generate verifiable certificates for CV building.

## Tech Stack
- Frontend: Flutter (Dart)
- Backend: Firebase (Auth, Firestore)
- AI Service: OpenAI API (Career Guidance)
- Verification: QR Code Generation
